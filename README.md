# Celine Lum — Portfolio

Personal portfolio for Celine Lum, a game designer, narrative designer, and programmer working across gameplay systems, interactive narrative, rapid prototyping, and production game design.

## Live site

[celinelumqr.github.io/portfolio](https://celinelumqr.github.io/portfolio)

## Built with

- React
- Tailwind CSS
- CSS Modules
- EmailJS
- GitHub Pages

## Local development

### Prerequisites

- Node.js
- npm

Install the dependencies:

```sh
npm install
```

Start the development server:

```sh
npm start
```

The site will be available at [http://localhost:3000](http://localhost:3000).

## Available scripts

### `npm start`

Runs the site in development mode.

### `npm test`

Runs the test suite in interactive watch mode.

### `npm run build`

Creates an optimized production build in the `build` directory.

### `npm run deploy`

Builds and deploys the portfolio to GitHub Pages.

## Project structure

```text
public/                 Static files, résumé, and site icons
src/components/        Shared interface components
src/pages/             Homepage, About, Projects, and Contact sections
src/static/images/     Project thumbnails and imagery
```
